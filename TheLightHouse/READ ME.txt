🎵 The Light House

Music is the beacon to our lives

The Light House is a concert venue booking system built with PHP and MySQL. It has three separate portals: customers book tickets, performers request concert sessions, and admins approve sessions and manage users.

Features
Customer portal (UI_1/)
Register and log in
View today's concert schedule
Search sessions by name or date
Choose a seating zone (A–F) and pay with account balance
Top up balance (PromptPay, TrueMoney Wallet, credit card, PayPal)
View and cancel booked tickets (with automatic refund)
Edit account details
Performer portal (UI_performer/)
Register and log in
Reserve a concert session (title, date, time, ticket price)
Request equipment for a session
View, edit, and cancel their own sessions
Admin portal (UI_admin/)
Approve or reject session requests
Review equipment requests
View all bookings
Ban / unban customers and performers
Business rules (enforced in the database)

These are implemented as MySQL triggers and stored procedures, so they apply no matter which page makes the change.

Rule	Where
Max 200 tickets per zone and 1,200 per session (6 zones)	check_zone_and_session_availability trigger, process_payment procedure
Sessions last 2 hours and cannot overlap	validate_time_slot trigger
Bookings can only be cancelled at least 7 days before the show	check_cancellation_period trigger
Cancelled bookings are refunded to the customer's balance	refund_after_cancellation trigger
Payment fails if the balance is too low	process_payment procedure
Top-ups are logged in the payment table	topup_balance procedure
Tech stack
Backend: PHP 8 (mysqli)
Database: MySQL 5.7 (tables, triggers, stored procedures)
Frontend: HTML + CSS
Local server: MAMP / XAMPP
Project structure
TheLightHouse/
├── thelighthouse (4).sql   # Database dump (schema, triggers, procedures, sample data)
├── test.php                # Helper script that creates an admin account
├── UI_1/                   # Customer portal
├── UI_performer/           # Performer portal
└── UI_admin/               # Admin portal

Each portal has its own dbconn.php, style1.css, and navigation bar (top.php, top_p.php, top_a.php).

Database tables

admin, customer, performer, session, booking, payment, equipment

Getting started
1. Install a local server

Install MAMP or XAMPP, which include Apache, PHP, and MySQL.

2. Copy the project

Put the TheLightHouse folder inside your server's web root:

MAMP: htdocs/
XAMPP: htdocs/
3. Import the database
Open phpMyAdmin (usually http://localhost/phpMyAdmin).
Create a database named thelighthouse.
Select it, go to Import, and upload thelighthouse (4).sql.
4. Check the database connection

Each dbconn.php uses these defaults:

php
$mysqli = new mysqli('localhost', 'root', 'root', 'thelighthouse');

If your MySQL username or password is different (XAMPP uses root with an empty password by default), update all three files: UI_1/dbconn.php, UI_performer/dbconn.php, UI_admin/dbconn.php

5. Enable short open tags

The pages use the short <? ... ?> tag. In your php.ini, set:

ini
short_open_tag = On

Then restart Apache.

6. Create an admin account (optional)

The SQL dump may already include an admin. If not, open http://localhost/TheLightHouse/test.php once to create one (username root, password root). Delete or rename test.php afterward.

7. Open the app
Portal	URL
Customer	http://localhost/TheLightHouse/UI_1/login.php
Performer	http://localhost/TheLightHouse/UI_performer/login_p.php
Admin	http://localhost/TheLightHouse/UI_admin/login_a.php

Known limitations

This is a student project and is not meant for production use:

Some search queries (e.g. booking.php, requests.php) build SQL from user input directly and should be converted to prepared statements.
Database credentials are hard-coded in dbconn.php.
Payment methods are simulated; no real payment gateway is connected.
Assets and dbconn.php are duplicated in each portal folder.
